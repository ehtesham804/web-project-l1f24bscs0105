## Project Overview
This repository contains a responsive personal developer portfolio website built with modular **HTML5**, **CSS3**, and **Vanilla JavaScript**. It features an interactive Ubuntu Linux terminal emulator (`ehtesham@ucp-lahore`), dynamic project filtering, architecture modal popups, and a dark-mode cybersecurity aesthetic.

## File Structure
```text
├── index.html   # Main semantic HTML5 structure
├── style.css    # Custom dark-mode styling, CSS Grid & Flexbox responsiveness
├── script.js    # Interactive terminal logic, project filter, and modal handlers
└── README.md    # Project documentation and setup instructions
```

## Key Features
1. **Interactive Ubuntu Terminal:** Supports live commands (`help`, `whoami`, `skills`, `projects`, `ucp`, `clear`).
2. **Project Filter & Modal Architecture View:** Filter coursework and FYP projects (*NextGen Freelance*, *Cybersecurity Simulator in C++*, *8086 Assembly Utility*) by category.
3. **Responsive Layout:** Mobile-first navigation and adaptive CSS Grid across desktop, tablet, and mobile screens.

## How to Run Locally
1. Extract the ZIP archive into a folder.
2. Open the folder in **Visual Studio Code**.
3. Double-click `index.html` to open it in any browser, or run it using the **Live Server** extension in VS Code.
